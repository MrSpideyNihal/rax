# Security Policy

## Reporting a vulnerability

Please use GitHub's [private vulnerability reporting](https://github.com/MrSpideyNihal/rax/security/advisories/new). Do not open a public issue.

Include the affected version, the impact, and steps to reproduce. This is a small project, so responses are best effort, but reports are taken seriously.

## Supported versions

Only the latest commit on `main` is supported. RAX is pre-release.

## Scope

In scope: `rax-host` and `rax-cli`, including memory safety of FFI code and DLL loading.

Bugs in upstream projects such as crosvm or gfxstream should go to those projects, but a note here is welcome if RAX is affected.
